The selection crop locates the intended child. It is not guaranteed to contain a complete face. Legacy identity contracts supplied only that crop on the initial drawing and review; a partial selection could therefore leave both stages without the nose, mouth and chin. The v4/v5 prompt also required flat separated shadows. Historical requests and receipts keep their exact contracts.

If rendering used that window, the saved candidate waits for a fresh tick. Re-entry reviews the same pixels and never repaints them. Legacy review windows stay at 90 seconds.
