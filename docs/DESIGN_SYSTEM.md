# מערכת העיצוב — "Storybook Collage"

חי ב־`/design-system`. טוקנים: `src/styles/tokens.css`. רכיבים: `src/styles/ui.css` (prefix `fm-`), `src/ui/*`. המשחק: `src/game/game.css`.

## עקרונות

1. **שני קהלים.** ההורה קונה (נקי, אמין, פרימיום). הילד משחק (גדול, צבעוני, מיידי, בלי טקסט מיותר).
2. **חוק ה־8.** כל ריווח, גובה, רדיוס וגובה־שורה הם כפולות של 8px. `--space-0-5` (4px) רק לכוונון אייקון/טקסט.
3. **טוקנים בלבד.** אין מספרי קסם ב־CSS של רכיבים. צבע חדש = טוקן חדש.
4. **נייר מורם.** כפתורים עם צל 4px שנדחס בלחיצה; כרטיסים עם צל רך; סטיקרים עם קו לבן 4px.
5. **ילד לא נכשל.** אין X אדום, אין צליל כישלון, אין לבבות, אין "נסו שוב". טעות = אדווה + "פופ". אין CTA/חנות/תפריט בתוך המשחק.

## המשחק

- **גובה יעד של הילד:** ~4% / 3% / 2.5% מגובה הסצנה (בארט הסופי). ה־hitbox גדול מהציור ולעולם לא קטן מ־48px מסך.
- **משוב:** 300–800ms לתגובה; חגיגת עולם ארוכה יותר; חלקיקים לפי עולם (בועות/כוכבים/עלים/קונפטי/פירות/ניצוצות).
- **בועות דיבור** ב־screen space (קריאות בכל זום), פונט Fredoka 20/32, מסגרת דיו.
- **סרגל עליון:** מפה · שם העולם · 1/3 · זום · איפוס · צליל. זהו.
- **טלפון לאורך:** הסצנה גדולה מה־viewport (cover), גוררים; טיפ עדין "הכי כיף לרוחב" — לא חוסמים.
