# איפה אני? — משחק חפש־ומצא אישי לילדים

תמונה אחת → דמות אישית → מחבואים בעולמות מאוירים.
Next.js App Router, TypeScript, Prisma, React. הגרסאות המדויקות נעולות ב־package-lock.json.

## הרצה מקומית ללא שירותים בתשלום

1. התקינו Node.js 22.
2. העתיקו את `.env.example` ל־`.env` ובדקו שהספקים המקומיים הם mocks וש־DATABASE_URL הוא קובץ SQLite מקומי.
3. הריצו:

```bash
npm ci
npm run setup
npm run dev
```

`setup` משנה סכימה, ולכן בודק תחילה את יעד מסד הנתונים. אין להריץ אותו על חיבור QA/ייצור לצורך פיתוח.
אין צורך במפתח AI לבדיקות. אין להעתיק קובצי env של שרת אל סביבת הבדיקות.

## מפת המוצר הנוכחי

- האתר, הוויזארד, יצירה, ספרייה, אדמין והשחקן נמצאים באותו יישום.
- הקטלוג מפריד בין **עולם** (מסע בן תשעה בורדים), בורד, מחבוא וגרסת תוכן.
- מנוע local-patch קיים במסלול היצירה, מאחורי בחירת מנוע מפורשת ב־QA.
  הוא מייצר זהות מאושרת, טלאים, ביקורות, יעדים וקונפיג משחק; אינו ברירת מחדל לכל סביבה.
- משחקים ישנים שומרים את גרסת הסצנה ומסלול המנוע שלהם. לא ממירים אותם אוטומטית.
- בלשים חדשים במסלול המוכשר: תשעה לוחות, שלושה מחבואים בכל לוח, 27 בסך הכול.
  שיפוט משולב אחד ב־SOL 6.1 LOW לכל תמונה, תקרת עולם רגילה של $4 וללא הרחבה אוטומטית.
  גרסאות מורשת שומרות את חוזי המחבואים, השיפוט והפרסום המקוריים שלהן.
- הדרכון מחובר להתקדמות המשחק, לחותמות, לתגליות ולמסך הסיום.
  תוכן עתידי נשאר חסום עד שיש לו ארט, חוזה וגרסת מנוע נתמכים; קטלוג לבדו אינו מוצר מוכן.
- PayMe עדיין שלד שאינו מבצע רכישה אמיתית. אין לראות במצב QA אישור לפתיחת מכירות.

מצב הקוד אינו הוכחה למצב הפריסה. את הקומיט, הפרויקט וההגדרות הטעונות ב־QA בודקים בכל פריסה.

## פקודות בדיקה ותחזוקה

| פקודה | תפקיד |
| --- | --- |
| `npm run check -- --maxWorkers=4` | TypeScript מחמיר + כל בדיקות היחידה והאינטגרציה המקומיות |
| `npm run typecheck` | גם src, content והסקריפטים המנוהלים ב־Git; אוסר משתנים ופרמטרים לא־בשימוש |
| `npm run check:work` | שם תאימות ל־typecheck; אינו מאמת ניסויים פרטיים מתוך work/ |
| `npm run scenes:validate` | סכימות סצנה ונתוני עיצוב שלבים; לא אישור חזותי |
| `npm run adventures:validate` | טיוטות ותוכן הספר; ב־ready גם נכסים ו־hash |
| `npm run smoke` | זרימת רכישה→יצירה→לינק ללא דפדפן; משתמש בספקים וב־DB מהסביבה ועלול להוציא כסף |
| `npm run db:guard` | בדיקה ללא חיבור DB: יעד מוכר וסכימת Postgres מפורשת |
| `npm run db:sql` | חידוש סכימת SQLite של הבדיקות אחרי שינוי schema.prisma |
| `npm run db:reset` | **מוחק נתונים** ביעד שנבחר; לא פקודת ניקיון של הפרויקט |

בדיקות עם ראיות פרטיות עשויות להופיע כ־skipped; זה אינו pass ואינו הוכחה לאיכות חזותית.
אין להריץ smoke כבדיקה חינמית בלי לוודא mocks ומסד נתונים מקומי ייעודי.
פרטים על סקריפטים ידניים והיסטוריים: [scripts/README.md](scripts/README.md).

## איחוד גרסאות והכנה לתשלום — 24.10.2026

ענף ברירת המחדל הוא `master`. פריסות Git אוטומטיות כבויות ב־`vercel.json`: דחיפה או מיזוג אינם פותחים מכירות או מקדמים דומיין. שחרור QA הוא build אחד של SHA נדחף שעבר את כל שלוש עבודות ה־CI, בדיקת build/פרטיות, קידום אותו build ואימות דפדפן. אין להפעיל את פרויקט הייצור הישן.

```bash
npm run payments:preflight -- --target qa --provider mock
npm run payments:preflight -- --target production --provider payme
```

הפקודה הראשונה מאשרת סימולציית QA; השנייה חייבת להחזיר exit 2 כל עוד PayMe והחוזים הכספיים אינם מוכשרים. זו בדיקת קוד ללא רשת, credentials או DB — לא אישור ספק או פריסה. הגדרת מפתחות אינה הוכחת מוכנות, ו־env חוסם הפעלת מסחר/יצירה בתשלום עם אדפטר לא מוכשר.

ראו את [הכנת התשלום והחסמים שנותרו](docs/PREPRODUCTION_PAYMENT_VERIFICATION_20261005.md#preparation-update--2026-10-24). יעד עלות $3–4 למשחק חדש עדיין דורש מדידה אמיתית; תקרת תקציב אינה מחיר ספק מובטח.
